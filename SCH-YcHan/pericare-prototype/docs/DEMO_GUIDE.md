# v6.1 시연 순서

1. `화면 가득 보기`로 지도를 넓힙니다. 일반병상 128개·ICU 12개(8.6%)의 축소 구성을 확인합니다. 기본 화면에서 현재 추적 입원 60명과 7일 운영 기간을 확인합니다. 기존 환자는 수술 전·수술 중·회복실·ICU·병동에 나뉘어 있습니다.
2. 1분 또는 5분 배속으로 시뮬레이션을 시작하고 환자 DEMO-004를 선택합니다. 평가·예약·장비 준비·수술 종료·간호사 동행·ICU 입실을 봅니다.
3. `지도 도구 → 구역 이동`에서 `퇴원·출구`와 `입원 접수`을 선택합니다. 이미 회복한 병동 환자는 담당 외과의와 간호사 판단을 거쳐 나가고, 새 환자는 접수와 입원 인계를 거쳐 들어옵니다. 모든 새 수술 환자를 몇 시간 만에 퇴원시키는 구조가 아닙니다.
4. +1일 또는 운영 배속으로 여러 날을 진행합니다. 운영 날짜, 현재 입원, 신규 입원·병원 퇴원, ICU와 병동 상태가 계속 갱신됩니다.
5. 환자 화면의 `현재 입원`/`병원 퇴원`/`전체 이력`을 비교합니다. 관측된 입원·수술·퇴원 시각과 잔여기간 예측을 구별합니다.
6. 병상 계획에서 24시간 실제 점유·확정 예약을 봅니다. 가용 예상이 지나도 실제 환자를 퇴실시키지 않습니다.
7. 상단 `설정 → 데이터 연결`에서 합성 형식 예제 `recorded-replay.json`을 불러옵니다. 미래 입원 사례는 입원 시각 이전에 보이지 않고, 17분의 관측은 그 시각부터 보이며, 기록된 병원 퇴원은 150분에 반영됩니다. 실제 자료에서 자동 진료 판단을 만들지 않는 경계를 설명합니다.

새 자료 연결은 현재 화면의 자료·예약을 교체합니다. 운영 감사는 보관됩니다. 기본 합성 시연으로 돌아오려면 설정 → 다시 시작합니다. 화면 가득 보기·확대·구역 선택·환자 선택 목록·큰 글씨·테마를 사용할 수 있으며, 환자 진료 판단을 사용자에게 묻는 버튼은 없습니다.

상세 패널을 닫은 뒤 같은 환자를 다시 선택해 열 수 있습니다. 출구 아이콘이 사라져도 열어둔 관측 종료 이력은 유지됩니다. 실제 자료에 퇴실 예상이 없으면 미확인으로 표시되며, 병상 점유와 환자 위치가 충돌하는 자료는 기존 화면을 바꾸지 않고 거부합니다.
