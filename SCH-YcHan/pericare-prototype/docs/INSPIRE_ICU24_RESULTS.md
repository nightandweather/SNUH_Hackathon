# INSPIRE ICU24 첫 모델 학습·연결 검증 결과

2026년 10월 16일(한국시간), 로컬 INSPIRE 1.4.2 원본으로 **수술실 입실시점의 수술 후 24시간 이내 ICU 신규 입실 확률**을 학습했습니다. 아래는 환자 식별자·개별 예측이 없는 집계 결과입니다. 실행 방법과 정답 구성은 [구현 안내](INSPIRE_ICU24.md)를 참고하세요.

## 예측 과제와 사용 자료

| 항목 | 이번 실행 |
|---|---|
| 데이터 | INSPIRE 1.4.2 |
| 예측 시점 | PREOP: 수술실 입실 `orin_time` |
| 정답 | 같은 입원에서 수술 종료~종료 후 1,440분 사이에 기록된 ICU 신규 입실 |
| 코호트 | 18~90세, ASA 1~5, 입원별 첫 수술과 시간·추적 조건 충족 |
| 입력 | 기본정보·수술 특성, 예측 시점까지 가용한 Hb·크레아티닌·혈소판·알부민·젖산과 경과시간 |
| 검사 가용성 가정 | 측정시각+60분 이후 사용, 최근 30일 범위 |
| 수술 중 생체신호 | 이번 PREOP 학습에는 사용하지 않음 |
| 선택 모델 | HistGradientBoostingClassifier, 별도 환자 자료로 sigmoid 확률 보정 |
| 적용 단계 | PREOP만. OR/PACU/ICU/병동 예측은 이번 가중치의 적용 범위 밖 |
| 난수 seed | 26 |

ICU 이용은 관측된 진료 결과입니다. 집중관리의 임상적 필요나 비예정 입실의 정답은 아닙니다. 원본의 다른 입원 ICU 시각은 이번 입원 양성으로 사용하지 않습니다. 퇴원 뒤 먼 미래에 ICU 기록이 있다는 이유로 수술 사례를 제외하지 않고, 별도의 감사 항목으로 집계합니다.

## 코호트와 환자 분할

원본 130,960건·99,886명에서 조건을 적용한 결과, **122,442건·97,116명**을 사용했습니다. 양성은 11,403건입니다. 환자 한 명의 모든 입원·수술은 같은 분할에 두었습니다.

| 분할 | 환자 수 | 수술·예측 행 수 | ICU 입실 양성 |
|---|---:|---:|---:|
| 학습 60% | 58,268 | 73,419 | 6,861 |
| 모델 선택·기준 선택용 검증 15% | 14,568 | 18,443 | 1,693 |
| 확률 보정 10% | 9,712 | 12,262 | 1,143 |
| 최종 시험 15% | 14,568 | 18,318 | 1,706 |

반복 환자가 여러 수술을 가질 수 있어 환자 수 비율과 수술 수 비율은 정확히 같지 않습니다. 이번 실행은 수술별 예측 시점이 한 개입니다.

## 모델 선택과 최종 시험 성능

검증자료에서 보정 전 log loss는 로지스틱 회귀 **0.19396**, HistGradientBoosting **0.17520**으로 후자를 선택했습니다. 보정은 별도 보정 환자로 수행했으며, 최종 시험 환자는 선택·보정·기준 조정에 사용하지 않았습니다.

| 지표 | 최종 시험 결과 | 환자 단위 bootstrap 95% 구간 |
|---|---:|---:|
| AUROC | 0.9295 | 0.9242~0.9350 |
| AP: average precision (`auprc`) | 0.6467 | 0.6204~0.6692 |
| Brier score | 0.05085 | 0.04886~0.05260 |
| Log loss | 0.17233 | 0.16559~0.17848 |

시험자료의 ICU 입실 비율은 **9.31%**입니다. 불확실성 구간은 환자 전체를 묶어 재표집한 100회 percentile bootstrap 결과이며, 외부 기관에서의 성능 구간은 아닙니다.

검증자료에서 민감도 90% 이상을 목표로 선택한 확률 기준은 **0.04982**입니다. 이 기준을 고정해 시험자료에 적용한 결과는 다음과 같습니다.

| 지표 | 결과 |
|---|---:|
| 민감도 | 90.21% |
| 특이도 | 80.70% |
| 양성예측도 | 32.43% |
| 음성예측도 | 98.77% |
| 기준 이상으로 분류된 비율 | 25.90% |
| 실제 입실·양성 분류 | 1,539건 |
| 실제 미입실·양성 분류 | 3,206건 |
| 실제 입실·음성 분류 | 167건 |
| 실제 미입실·음성 분류 | 13,406건 |

입실 환자를 많이 포착하는 기준이므로 양성 분류의 약 3분의 2는 실제 ICU 입실이 없었습니다. 이 기준은 연구 평가용이며 병상 예약이나 임상 처치 기준으로 확정한 값이 아닙니다. 추가 평가에서는 오경보 부담, 수술 종류별 성능과 실제 가용 자원을 함께 확인해야 합니다.

## PeriCare 연결 확인

실제 원본에서 만든 PREOP 스냅샷 한 건으로 모델 서버와 PeriCare를 HTTP로 연결했습니다.

- 학습 전처리 행과 앱에서 전송한 모든 모델 특징의 일치 확인.
- 같은 학습 모델이 앱에 연결되어 확률만 반환함을 확인.
- 집중관리 필요 점수·ICU/입원 기간·신뢰도는 미지원으로 유지.
- ICU 등 미학습 단계에서는 예측을 보류.
- 병상 예약 보류와 실제 자료의 가상 진료 자동화 비활성 확인.
- 해당 단일 요청에서 측정된 추론시간 **39.702ms**. 동시 요청 부하 시험 결과는 아님.

원본의 실제 미래 수술 시작·종료와 ICU·퇴원·사망·정답은 앱 스냅샷에 포함하지 않았습니다. 앱 필수 일정은 명시적으로 제공한 계획값이며, `case_relative` 시간축과 병상 목록 없음으로 가져왔습니다.

## 해석의 범위

한 기관의 후향적 자료를 환자별 무작위 분할한 내부 검증입니다. 외부 기관·미래 기간·전향적 운영 검증은 수행하지 않았습니다. 검사 가용 지연과 수술 특성의 사전 가용성에는 명시적인 가정이 있습니다. 전원·외부병원 ICU 입실·기록 누락을 모두 판별할 수 없고, 기관별 예정 ICU 이용 관행도 정답에 반영될 수 있습니다.

수술 중 동적 예측용 전처리·학습 경로는 구현했지만 해당 모델은 아직 학습하지 않았습니다. ICU 체류기간·집중관리 필요 모델과 실제 병상 운영 효과도 별도 개발·검증 과제입니다.
