## v6.1에서 추가로 확인한 동작

- 같은 시각의 실제 전실·입원 종료·다음 재실을 함께 처리하며, 실제 중복 점유는 현재 시각·재생 커서·재원과 함께 전체 요청을 롤백.
- 이미 관측된 ICU 재실은 미래 수술 예정 시각보다 우선. 기관별 문자열 병상 ID도 실제 점유 연결로 인식.
- ICU·병동 환자의 수술 종료 재수신 시 위치 보존, 최초 완료만 수술 수에 집계. 실제 종료와 정보 수신 시각을 분리.
- 지연 관측을 측정 시각별로 교체·정렬. 가용 시각 이전에는 보이지 않고, 늦게 받았다고 현재 측정으로 처리하지 않음.
- 입원 종료 이후 새 측정은 거부하고, 종료 이전 측정의 지연 수신은 이력으로 보관. 종료 상태와 현재 예측 제외 유지.
- 환자 위치/점유 불일치 입력 거부, 불러오기 실패 시 기존 자료 보존. 미제공 퇴실 전망은 미확인으로 표시하고 미래 예약에서 제외.
- 닫은 같은 환자 재선택, 출구 아이콘이 없어진 뒤 종료 이력, 새 자료 연결 후 강조·단계 필터 정리.
- 긴 연결키의 지도 단축 표식, 원본 ID·원본 연결과 표식의 갱신 안정성.
- v6.0 → v6.1에서 시각·재원·예약 유지, 초기화 및 이전 상태 재보관 없이 현재 진행 일시정지.

## v6 화면·병상 검사

- 일반 128·성인 ICU 12(8.57%) 병상, ICU 내부 8+4, 가동 10개와 기존 ICU 외부 점유를 별도로 유지.
- 이전 모의 상태의 실제 점유와 시각을 보관한 뒤 새 병상 시나리오를 시작. v6 재시작과 가져온 자료는 현재 시각·재고를 보존.
- 1680×1100에서 지도 폭 1,500px 초과·높이 760px 초과, 4개 작은 지표, 고정 세로 메뉴/최근 기록 패널 제거.
- 브라우저 전체 화면과 지원하지 않는 경우의 창 내부 확대, 시계·재생 조작 유지, 종료와 Esc 복원.
- 환자 선택 후에만 상세 패널 표시, 닫기·Esc·재갱신 이후 닫힘 유지.
- 창을 390px로 줄여도 문서 가로 넘침 없음. 지도 내부 이동으로 아이콘을 읽을 수 있는 배율을 유지. 사용자가 전체 보기를 누르면 작은 전체 도식을 선택할 수 있음.
- 위험·경과 화면의 열린 입력 이력은 실제 화면 갱신 뒤에도 유지.

## 확인한 핵심 동작

- 기존 입원 60명, 7일 신규 168명. 실제 입원 전에는 미래 환자·관측·종료를 화면과 모델 요청에 노출하지 않음.
- 식이·보행·통증·상처·안정 경과를 확인한 가상 담당 외과의와 병동 간호사 퇴원, 병상 비우기와 청소.
- 짧은 잔여기간 예측 자체로 실제 퇴원을 발생시키지 않음.
- 전체 7일에서 시작 재원+신규 입원-관측 종료=현재 재원을 유지하고, ICU·병동 병상을 동시에 중복 점유하지 않음.
- 수술실의 동시 점유 중복 없음. 7일 마지막에는 진행 중 환자를 남기고 자동 일시정지.
- 기록 시각 17분처럼 5분 배수가 아닌 사건도 해당 시각에만 반영.
- 기록 불러오기 후 공통 시계가 보존되고, 실측·진료 결정·직원 위치를 합성하지 않음.
- 관측 API가 시각을 앞으로 이동해도 중간 입원·수술·퇴원 기록을 건너뛰지 않음.
- 실제 미래 종료는 별도 재생 큐에만 존재. 현재 스냅샷 내보내기도 아직 입원하지 않은 사례와 미래 큐를 제외.
- 사망·기관 전원은 귀가 퇴원과 구별. 알 수 없는 outcome을 정상 퇴원으로 가정하지 않음.
- 상대시각 또는 미제공 병상 재고에서 자원 경쟁·예약 계산을 차단.
- 퇴원 환자는 현재 위험·예약 대상에서 제외하고 이력에 남김. 새 환자는 선택 목록에 반영.
- 일시정지, 초점·스크롤·열린 입력 이력, 테마·큰 글씨·이동 효과와 모바일 3메뉴 유지.

## 검증 범위

Docker 엔진이 없는 실행 환경이므로 Docker 이미지 빌드와 컨테이너 기동, 실제 Windows Docker Desktop 실행은 검증하지 않았습니다. 동일 Python 서버와 실제 Chromium UI를 직접 실행했습니다. 첫 Docker 빌드에는 기반 이미지 다운로드가 필요합니다.

실제 EMR·학습 모델·확률 보정·기관 인증/RBAC·간호 인력 최적 배치·전체 WCAG 인증·스크린리더·임상 효과는 검증하지 않았습니다. 기본 합성 분포·회복·기간 범위는 가정입니다. 승인된 실제 자료의 전체 체류 분포를 집계한 결과가 아닙니다. QA 한글 화면 검토에만 Noto Sans KR를 주입했고 앱은 시스템 글꼴로 오프라인 동작합니다.
