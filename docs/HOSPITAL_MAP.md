# v6.1 병원 지도

수술 전 대기·수술실·회복실·외과계 ICU·심장계 ICU·일반병동·입원 접수·퇴원 출구의 8구역입니다. 기본 합성 코호트 60명과 이후 신규 환자를 관측된 위치에 표시합니다. 입원 인계와 퇴원 간호도 이동 경로로 보여줍니다.

환자 번호와 위험 숫자, ICU 실제 재실/예약/청소/가동 중지, 담당 의료진을 구별합니다. 실제 인수가 끝나기 전 애니메이션 목표 병상을 실제 점유로 바꾸지 않습니다. 모든 재실·배정은 원자적 상태에서 결정합니다.

환자는 입원 시각부터 선택 목록에 추가됩니다. 퇴원 인계 중 출구로 이동하고 실제 퇴원 뒤 최근 30분·최대 8명만 출구에 남겨 오래된 퇴원 아이콘이 병동을 채우지 않게 합니다. 나머지 이력은 환자 화면에서 확인합니다.

지도 도구의 구역 선택, 확대/축소/전체 보기, 드래그·방향키, 환자 선택 목록, 고위험/수술/병동/이동/퇴원 강조를 제공합니다. 기본 전체 보기와 세밀한 구역 보기를 구분합니다. 화면 가득 보기에서도 시계와 재생 조작을 유지합니다. 아이콘 선택 시에만 상세 패널이 열리며 닫기·Esc로 닫습니다. 큰 글씨·테마·이동 효과 설정은 유지됩니다. 일시정지와 연결 끊김에서는 움직이지 않습니다.

합성 직원은 의료진 13개 역할 아이콘이며 실제 직원 위치를 나타내지 않습니다. 실제 자료에서는 관측된 환자 위치만 표시하고 제공받지 않은 의료진 위치를 생성하지 않습니다. ICU 관측은 있지만 병상 연결키가 없는 경우 해당 ICU 구역에 배치하고 병상을 실제로 점유했다고 만들어내지 않습니다. 상대시각 코호트에는 실제 동시성이 없다는 문구와 예약 차단을 적용합니다.

일반병동을 가장 넓은 영역으로 확장하고, 상시 세로 메뉴·큰 통계 카드·최근 기록 패널을 제거했습니다. ICU 12개 물리 병상을 그리며 일반 128개는 실제 배정 수와 함께 표시합니다. 지도 전체를 맞출 때 창 크기 변경·전체 화면 전환에도 다시 맞춥니다. 도식의 면적은 실제 건축 면적을 나타내지 않습니다.

작은 화면에서는 지도 내부를 이동하는 배율로 시작하며, 데스크톱에서 작은 창으로 바꾸어도 너무 작은 전체 도식으로 고정되지 않습니다. 직접 전체 보기를 선택하면 전체 도식을 볼 수 있습니다.

긴 환자·병상 연결키는 지도에 P/B 단축 표식을 배정해 아이콘끼리 텍스트가 겹치지 않게 합니다. 표식은 동일 자료를 보는 동안 유지되고, 새 자료 연결 시 다시 배정합니다. 실제 연결키는 선택 목록·툴팁·상세·API에 그대로 남으며, 지도 표식을 원본 ID로 사용하지 않습니다.
