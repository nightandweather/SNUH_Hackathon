# SICU LINK · TEAM 4 · v25

병상과 간호 인력, 환자 이송 흐름을 한눈에 보는 외과계 ICU 간호 상황판입니다. 가상 병원 A·B·C의 7개 ICU, 52병상을 제공합니다.

## 실행

Python 3.8 이상이 필요합니다. 추가 패키지 설치나 빌드는 없습니다.

```bash
cd sicu-link
python3 server.py
```

브라우저에서 [http://127.0.0.1:8003/?lang=ko](http://127.0.0.1:8003/?lang=ko)를 엽니다. 터미널은 열어 두고, 종료할 때 `Ctrl+C`를 누릅니다.

- macOS: `start-sicu-link.command` 실행
- Windows: `start-sicu-link.cmd` 실행 또는 `python server.py`

8003 포트를 사용 중이면 `python3 server.py --port 8004`로 실행합니다.

## 사용

처음 화면에서 병원 또는 통합 관제를 선택합니다. 상단 SICU LINK 로고를 누르면 다시 선택할 수 있습니다.

- 병동·환자 목록에서 병상, 담당 간호사, 환자 상태를 확인합니다.
- 운영 계획에서 예약과 이송 흐름을 살펴봅니다.
- 재생 버튼으로 가상 상태 변화와 이송 장면을 함께 봅니다.

환자 상세 상단에 주진단·주수술명을, 연결 장비에 종류·유량·모드·개수·위치를 표시합니다. GCS는 E/V/M 항목으로 표시하며, 원본에 없는 보강 값은 `시연 예시`로 구분합니다. 간호사에게 마우스를 올리면 담당 병상이 점선으로 표시됩니다.

화면 코드는 `web/`에 있습니다. 수정한 뒤 브라우저를 새로고침하면 반영됩니다.

포함된 가상 자료로 동작하는 시연 버전입니다. 실제 환자 정보·병원 로그인·모델 API에 연결되어 있지 않으며, 통합 관제 선택은 화면의 표시 범위를 바꾸는 기능입니다.
