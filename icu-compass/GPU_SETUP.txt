서버: ICUBoardQwen2 / NVIDIA RTX A5000 24GB
JupyterLab: https://s4w66hdi1zteriq8oyfb8wzm.khdp.net/lab
GPU 런타임: /home/khdp-user/workspace/icu-runtime
모델: Qwen/Qwen3-VL-8B-Instruct-FP8 (FP8 가중치, BF16 활성화, 동시 요청 1개, 문맥 8192)
내부 모델 저장소: http://huggingface.khdp-cache-server

시작: 앱 폴더에서 bash start_gpu.sh
상태: bash status_gpu.sh
실제 텍스트/영상 호출 검증: ../icu-runtime/venv/bin/python verify_gpu.py
인계 검증: LLM_BASE_URL=http://127.0.0.1:8091/v1 LLM_MODEL=Qwen/Qwen3-VL-8B-Instruct-FP8 ../icu-runtime/venv/bin/python verify_handover.py --model

앱은 서버 내부 127.0.0.1:8000, 모델 API는 127.0.0.1:8091에서 동작한다.
외부 접속은 Jupyter 인증을 거치는 /proxy/8000/ 경로를 사용한다.
Jupyter 프록시 확장 설치 후 Jupyter 재시작이 필요하다.
이 문서는 실행 방법이며 실제 배포/검증 완료를 뜻하지 않는다. 검증 결과는 verification/gpu-live.json 등으로 확인한다.

GPU 시작 스크립트는 ICU_COHORT=surgical로 실행한다. 공개 MIMIC-IV 데모에서 원본 careunit이 외과계인 73개 ICU 재원 기록만 선택한다. SICU 29, CVICU 25, TSICU 16, Neuro SICU 3개이며 내외과 혼합 ICU 및 합성 소아·신생아 기록은 제외한다. 4개 병동·32병상·근무조당 간호사 20명은 시연 배치다.
K-MIMIC는 서버 datasets 폴더에서 읽을 수 있지만 앱 연결 및 외과 코호트 선정은 별도 작업이다.
환자별 중증도는 현재 앱의 임시 규칙 지표이며 APRICOT-M을 설치하거나 검증한 상태가 아니다.
원본 K-MIMIC 데이터는 KHDP 안에서 사용한다.

예산: 최대 24시간·총 20,000원. 최초 승인 기준 종료 시한 2026-10-17 16:19 KST.
앱이나 모델 프로세스 종료는 Pod 과금 종료와 다르다. KHDP에서 Pod 종료 상태를 확인해야 한다.
Pod 삭제 전에 보존할 코드와 결과를 updown에 백업한다. GPU 캐시/가상환경은 재설치할 수 있다.
