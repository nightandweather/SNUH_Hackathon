# KCD 2026 발표 구성

공식 주제는 **Agentic AI: Light and Shadow**입니다.
공식 인사말: https://datathon.kr/overview/welcome/

주최 측은 에이전트의 활용과 함께, 실패 지점과 실패를 알아내는 방법을 살펴보도록 요청합니다. 사전워크숍 안내자료 6–8쪽에서도 활용과 비판적 검토, 임상적 가치, 데이터 사이언스의 창의성, 전달력, 재현 가능성을 제시했습니다. 원본 안내자료는 이 저장소에 포함하지 않습니다.

## 발표의 중심

외과 ICU 환자 기록을 조회하고 간호사의 보고를 지원하는 상황판을 실제 화면으로 보여줍니다. 이어서 장비 기록, 결측값, 기록 시점, CXR 환자 매칭에서 발견한 문제와 수정 또는 보류한 결정을 설명합니다. CalMRL은 별도로 개발 중인 예측 모델로 소개하며 상황판 연동 및 K-MIMIC 외부 검증과 구분합니다.

## 7분 구성

1. ICU Compass: 외과 ICU 기록 조회와 간호 보고 지원 (20초)
2. 간호사가 확인해야 하는 정보와 범위 축소 (35초)
3. 8병상 상황판과 이송 재생 (45초)
4. 환자 기록과 평가 시점 (40초)
5. 간호 지원 LLM 실제 응답 (50초)
6. 개발 중 발견한 실패와 수정 (60초)
7. CalMRL 위험 예측 목표 (55초)
8. CXR이 없는 시점의 예측 (45초)
9. 현재 구현 범위와 재현 자료 (40초)
10. 다음 검증 (30초)

부록: 평가 항목과 발표 내용, 출처와 재현 자료.

## 결과 표현

- Python 132개 테스트와 JavaScript 40개 파일 문법 검사는 소프트웨어 확인 결과입니다. 임상 검증 결과로 표현하지 않습니다.
- CXR 모델 입력과 응답은 확인했으나 현재 상황판 환자의 동일 검사 영상 연결은 미완료입니다.
- CalMRL 성능 수치와 임상 효용은 아직 제시하지 않습니다.
- 의료진 이동과 31일 병상 배치는 시뮬레이션입니다.
- 현재 저장소는 비공개입니다. 코드의 공개 배포나 실제 환자 데이터 공개를 주장하지 않습니다.
- 발표 PDF와 PPT는 로컬 산출물로 관리하며, 환자 기록이 들어갈 수 있는 화면 캡처는 이 저장소에 자동 업로드하지 않습니다.

## 문장과 디자인

긴 홍보 문구와 반복되는 슬로건을 줄이고, 기능 이름과 관찰한 문제를 제목으로 씁니다. 실제 화면을 크게 배치하고 구현, 연구 목표, 남은 작업을 구분합니다. 자세한 설명은 발표자 노트로 옮깁니다.
