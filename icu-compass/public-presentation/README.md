# 공개 시연 스냅샷

기존 공유 사이트의 정적 화면을 독립 실행 가능한 형태로 보관합니다. 합성 시나리오이며 실제 K-MIMIC 환자·API 키·모델 호출은 포함하지 않습니다. 방문자별 브라우저 상태는 공유되지 않습니다.

프로젝트 루트에서 `python3 -m http.server 8080 --bind 127.0.0.1 --directory public-presentation` 실행 후 http://127.0.0.1:8080/ 으로 접속합니다.

이 폴더는 공개 사이트 소스의 현재 스냅샷입니다. 원본 Sites 저장소의 Git 이력이나 호스팅 자격증명은 복사하지 않았습니다.
